# Front-End Assignment 2 — TechWorld
## Implemented requirements
1. Flexbox navigation: logo + links aligned horizontally and vertically.
2. Flexbox cards: 3 cards, equal-height behavior, gaps and hover lift.
3. CSS Grid page layout: header, sidebar, main and footer using grid areas.
4. CSS Grid gallery: 9 local images, equal columns, gaps and hover captions.
5. Responsive media queries for tablet/mobile screens.
6. No Bootstrap/Tailwind/external UI libraries.
7. Shared external stylesheet: css/style.css.
